# Return policy

A customer may request a return within thirty days after the shipment is delivered. The order must be paid or fulfilled, and no return request may already be open for that order.

Allowed return reasons are damaged, wrong item, not as described, changed mind, and other. The return window is counted from the estimated delivery date once the shipment status is delivered.

A return request records the reason. It does not by itself move money or change the shipping address.
