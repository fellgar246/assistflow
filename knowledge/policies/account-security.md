# Account security

To reset a password, the customer uses the recovery email already stored on the account. AssistFlow sends a one-time sign-in code to that recovery email. The code expires after fifteen minutes.

Support never asks for the current password, a payment instrument, or a full sign-in code in chat. If the recovery email is unavailable, the customer waits for a person to verify the account.

A successful reset replaces the password. It does not change the shipping address or open a refund.
