# Returns and refunds

A return can be requested after the shipment is delivered, within 30 days of the estimated delivery date, when the order is paid or fulfilled and no return is already open.

Allowed return reasons are damaged, wrong item, not as described, changed mind, and other.

A refund request can be recorded for a paid or fulfilled order. The amount cannot exceed the order total minus refund requests that are still requested, pending review, or approved. Rejected refund requests do not reduce the remaining amount.

A refund request is not a payment capture. Responses include the maximum amount in minor currency units and never include a payment instrument.
