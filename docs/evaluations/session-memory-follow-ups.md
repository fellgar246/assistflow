# Session memory follow-ups

Ten address follow-ups were scored twice. The expected result is the order the customer means, or a question when neither the message, the history window, nor session memory identifies an order.

| Session memory | Correct |
|---|---|
| On | 10 of 10 |
| Off | 7 of 10 |

The three misses with memory off are the follow-ups whose history window is empty or names a different order. With session memory on, the last order id from the prior tool result is used, and the current message still wins when it names an order. The same history window is available in both runs. Memory is not required when that window already holds the order id.
